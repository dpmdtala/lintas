Pencatatan Surat Masuk

Tanggal otomatis mengikuti hari ini dan tidak dapat diubah.
Wajib. Format PDF/JPG/PNG, maksimal 10 MB. Jika scanner komputer digunakan, lakukan scan melalui aplikasi driver scanner lalu pilih file hasil scan di sini. Browser web standar tidak dapat mengendalikan scanner USB secara langsung tanpa aplikasi/driver perantara.
Tombol Scan langsung mencoba membuka aplikasi pemindaian Windows jika tersedia. Setelah pemindaian selesai, pilih file hasil scan pada kolom di atas. Koneksi scanner otomatis bergantung pada aplikasi/driver di komputer.
Cetak Rekap Surat:

Daftar Surat Masuk Front Office

Daftar seluruh surat yang sudah diregistrasi Front Office, termasuk status pengiriman dan tindak lanjut Pengadministrasi Surat. Perubahan status ditandai dengan label merah pada kolom status.

Daftar Surat Masuk Front Office

Rekap Surat Masuk 3 Jam & Kirim ke SIAP

Periode ditentukan oleh waktu server WITA. Rekap menampilkan seluruh surat masuk pada hari berjalan berdasarkan waktu server WITA. Data surat asli tetap tersimpan di LINTAS.

Alur integrasi
  1. Muat rekap seluruh surat masuk pada hari berjalan berdasarkan waktu server WITA.
  2. Pratinjau dan buat bukti gambar rekap.
  3. Kirim bukti gambar dan laporan kegiatan ke SIAP. Status berhasil hanya ditampilkan setelah SIAP mengonfirmasi penerimaan.

Foto bukti berisi nomor registrasi, waktu, asal, nomor surat, perihal, dan status. Isi ringkas surat serta scan tidak disertakan.

Pratinjau bukti rekap yang akan dikirim sebagai foto laporan SIAP.

Pencatatan Surat Keluar

Catat setelah surat ditandatangani dan siap dikirim. Nomor agenda internal berbeda dari nomor surat resmi.

Wajib. PDF/JPG/PNG, maksimal 10 MB.
